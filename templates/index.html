MALL CUSTOMERS

Segmentación inteligente basada en análisis de datos

Problemática

El centro comercial carece de un modelo analítico que permita segmentar a sus clientes con base en variables como edad, ingresos y comportamiento de consumo, limitando la toma de decisiones estratégicas.

Objetivo

Desarrollar un modelo de segmentación mediante técnicas de clustering para optimizar decisiones comerciales.

Justificación

La segmentación permite identificar grupos homogéneos, mejorar estrategias de marketing y aumentar la rentabilidad.

Metodología

Se utilizó el algoritmo K-Means implementado en scikit-learn. Se seleccionaron variables relevantes, se preprocesaron los datos y se aplicó el método del codo para definir el número óptimo de clusters.

Modelo

K-Means agrupa datos minimizando la varianza intra-cluster. Se definió K=5 como valor óptimo para este caso.

Resultados

Se identificaron cinco segmentos de clientes con comportamientos diferenciados.
